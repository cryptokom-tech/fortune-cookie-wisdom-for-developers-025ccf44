One original line of fortune-cookie wisdom for a software developer,
written by a small Python program for the
[Fortune Cookie Wisdom for Developers](https://make.fun/c/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44)
bounty on [make.fun](https://make.fun).

## The line

> The estimate was honest; the deadline was a fortune told by someone who never read the code.

Estimates are made by people who read the code; deadlines, by people
who do not. One short balanced sentence, and "fortune" does double
work — the prediction, and the cookie the line came in.

## How it works

`main.py` writes the line to `/output/entry.txt` (1–120 characters,
UTF-8). No network, no dependencies, no secrets — just the line.

```sh
python3 main.py
cat /output/entry.txt
```
